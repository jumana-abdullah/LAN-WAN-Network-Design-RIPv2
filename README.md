# Network Design and Configuration Using RIPv2

## 📌 Project Overview

This academic project was developed as part of the Computer Networks course at the University College of Al-Khurmah, Taif University.

The project focuses on designing, configuring, and testing a multi-network topology using Cisco Packet Tracer. It demonstrates how multiple Local Area Networks (LANs) can communicate through a Wide Area Network (WAN) using dynamic routing.

## 🎯 Project Objectives

- Design and build a network topology using Cisco Packet Tracer.
- Configure IPv4 addresses for PCs and router interfaces.
- Establish connectivity between devices within the same network.
- Implement the RIP routing protocol.
- Enable communication between different networks.
- Verify network connectivity using ICMP Ping tests.

## 🖥️ Network Topology

The network consists of:

- 3 Routers (R1, R2, R3).
- 3 Switches.
- 6 PCs.
- 5 Local Area Networks (LANs).
- 2 Wide Area Network (WAN) links.

All devices use the IPv4 subnet mask:

`255.255.255.0`

## ⚙️ Technologies and Protocols

- Cisco Packet Tracer
- IPv4 Addressing
- Static IP Configuration
- LAN and WAN
- RIP Version 2 (RIPv2)
- ICMP (Ping)
- Router and Switch Configuration

## 🔧 Implementation Process

### 1. Network Topology Design

Created the complete network topology in Cisco Packet Tracer, connecting three routers, three switches, and six PCs across multiple network segments.

### 2. IP Address Configuration

Assigned static IPv4 addresses to all PCs and router interfaces.

Configured the appropriate default gateway for each PC and activated router interfaces using the `no shutdown` command.

### 3. Local Connectivity Testing

Performed Ping tests between devices within the same network to verify local connectivity and correct IP configuration.

### 4. Dynamic Routing Configuration

Configured the RIP routing protocol on all three routers to exchange routing information and enable communication between different network segments.

### 5. End-to-End Connectivity Testing

Performed additional Ping tests between devices located in different networks.

Successful ICMP replies confirmed that routing between the network segments was functioning correctly.

## ✅ Project Results

- Successfully designed and configured the network topology.
- Established local communication between devices.
- Implemented dynamic routing using RIPv2.
- Verified connectivity between different networks.
- Successfully completed end-to-end Ping tests.
